## Featured projects

### 🌗 [ShadowFix — Shadow Removal & Image Restoration](https://github.com/odra-bira/ShadowFix)
Investigated U-Net-based shadow removal using RGB and mask-guided approaches on the ISTD dataset. The project report records **30.19 dB PSNR** and **0.9514 SSIM** for its best model over 540 test images. Includes visual comparisons and a Gradio-based demonstration.

*PyTorch · U-Net · OpenCV · Image restoration*

### ♻️ [Trash Detection & Cleanliness Assessment](https://github.com/odra-bira/trash_detection)
YOLOv8-based litter detection with bounding-box visualization, trash-density heatmaps, and a heuristic cleanliness score. The published repository includes inference, training, and Gradio demo code; its original trained checkpoint is not included.

*Python · YOLOv8 · OpenCV · Gradio*

### 📚 [StudyEase — AI-Assisted Study Planning](https://github.com/odra-bira/studyease)
A study-planning application that organizes assignment workload into scheduled sessions. It combines an LLM-assisted planning workflow with a deterministic scheduler that checks constraints and adjusts plans.

*Python · FastAPI · React · LLM integrations*

### 🧍 [Real-Time Pose Detection & Exercise Tracking](https://github.com/odra-bira/Real-Time-Pose-Detection-and-Exercise-Tracking-main)
A webcam-based pose estimation notebook using body landmarks and elbow angles to count bicep-curl repetitions.

*Python · MediaPipe · OpenCV*

### 💬 [Comment Toxicity Classification](https://github.com/odra-bira/comment-toxicity-clean)
An experimental multi-label NLP classifier for six categories of toxic language using a bidirectional LSTM, with a Gradio interface. This project does not claim a validated benchmark score.

*TensorFlow · BiLSTM · NLP · Gradio*

### 🍎 [Fruit Quality Classification](https://github.com/odra-bira/agriculture-project)
A Flask application using a saved MobileNetV2-based Keras model to classify fresh and rotten apples, bananas, and oranges. Related to my [published work](https://doi.org/10.22214/ijraset.2025.68187).

*TensorFlow/Keras · MobileNetV2 · Flask*
